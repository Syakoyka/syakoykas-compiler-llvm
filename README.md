# syakoykas-compiler-llvm

Курсовой проект по дисциплине «Конструирование программного обеспечения» (2 курс). Разработка фронтенда компилятора для предметно-ориентированного языка (DSL) с использованием C++17 и инфраструктуры LLVM.

## Статус реализации
На текущем этапе **полностью реализован и протестирован лексический анализатор (лексер)**. Модули синтаксического анализа (парсер) и генерации кода находятся в разработке.

## Архитектура лексера
Лексер производит сканирование исходного текста и преобразование его в поток лексем с помощью матрицы состояний:
- **Алфавит и типы символов (`CharType`):** разделение входного потока на буквы, цифры, операторы, кавычки, слеши, пунктуацию и пробельные символы.
- **Табличный ДКА (`Transitions`):** детерминированный конечный автомат с явной матрицей переходов и массивом финальных состояний для эффективного распознавания лексем.
- **Позиционирование:** отслеживание номеров строк (`line`) и колонок (`column`) для детальной диагностике ошибок.

### Поддерживаемые токены (`TokenType`)
- **Ключевые слова:** `def`, `if`, `else`
- **Идентификаторы:** пользовательские имена переменных и функций
- **Литералы:** числовые (целые числа) и строковые литералы
- **Операторы:** арифметические знаки, операции сравнения и присваивания (`+`, `-`, `*`, `=`, `<`, `>`, `!`, многосимвольные операторы)
- **Пунктуация:** круглые, фигурные, квадратные скобки, запятые, точки с запятой
- **Служебные:** маркер конца файла (`TOKEN_EOF`) и токены лексических ошибок (`TOKEN_ERROR`)

Пробельные символы и однострочные комментарии (`//`) автоматически пропускаются. Некорректные символы классифицируются как ошибки лексического анализа.

## Структура проекта
- `include/lexer.hpp` — спецификация типов токенов, состояний автомата и интерфейс класса `Lexer`.
- `src/lexer.cpp` — реализация алгоритмов токенизации и табличного DFA.
- `src/main.cpp` — точка входа с базовыми тестами для проверки лексера.
- `examples/` — директория с примерами исходного кода на DSL.
