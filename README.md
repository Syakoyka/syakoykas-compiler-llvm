# syakoykas-compiler-llvm

> **Курсовой проект** по учебной дисциплине «Конструирование Программного Обеспечения» (2 курс).  
> **Тема:** Разработка компилятора для предметно-ориентированного языка программирования (DSL).

---

## Описание проекта

Проект представляет собой компилятор для узкоспециализированного языка программирования (DSL), написанный на **C++17** с использованием библиотеки **LLVM C++ API**. Компилятор выполняет полный цикл трансляции: от лексического анализа исходного текста до генерации промежуточного представления LLVM IR.

---

## Архитектура и структура конвейера

Трансляция кода выполняется в три основных этапа:

1. **Lexer (Лексический анализатор):** Читает исходный текст из файла `.dsl` посимвольно (с использованием принципа *Lookahead* для предпросмотра) и разбивает его на поток токенов. Автоматически прослеживает строки/колонки и игнорирует комментарии.
2. **Parser (Синтаксический анализатор):** Анализирует последовательность токенов на соответствие грамматике методом рекурсивного спуска и строит абстрактное синтаксическое дерево (**AST**).
3. **CodeGen (Генератор кода):** Обходит AST и генерирует промежуточный код **LLVM IR** с помощью `llvm::IRBuilder`.

## Спецификация входного DSL-языка

### 1. Алфавит языка
Алфавит входного языка включает следующие категории символов:
- **Буквы латинского алфавита:** `a–z`, `A–Z`
- **Десятичные цифры:** `0–9`
- **Специальные знаки:** символ подчёркивания `_`
- **Знаки арифметики и сравнения:** `=`, `+`, `-`, `*`, `/`, `<`, `>`, `!`
- **Разделители и скобки:** `;`, `,`, `:`, `(`, `)`, `{`, `}`
- **Символы комментариев:** `/` (в сочетаниях `//` и `/* ... */`)
- **Пробельные символы:** пробел, табуляция (`\t`), перенос строки (`\n`, `\r`)

---

### 2. Спецификация лексем (Lexical Tokens)

> **Особенность реализации Лексера:**  
> Лексический анализатор реализован **вручную** (метод сканирования на базе ДКА без использования `std::regex`).  
> Для распознавания составных операторов (например, `<=`, `==`, `//`, `/*`) используется метод **Lookahead (предпросмотр следующего символа)** через функцию `peek()`.

| Категория токена | Тип токена (`TokenType`) | Примеры лексем | Описание |
| :--- | :--- | :--- | :--- |
| **Ключевые слова** | `VAR`, `IF`, `WHILE`, `PRINT` | `var`, `if`, `while`, `print` | Зарезервированные слова управляющих конструкций |
| **Идентификаторы** | `IDENTIFIER` | `x`, `counter`, `my_var` | Начинаются с буквы или `_`, дальше буквы/цифры/`_` |
| **Числовые литералы** | `NUMBER` | `0`, `10`, `100` | Целочисленные литералы |
| **Оператор присваивания** | `ASSIGN` | `=` | Операция записи значения в переменную |
| **Арифметика** | `PLUS`, `MINUS`, `STAR`, `SLASH` | `+`, `-`, `*`, `/` | Бинарные арифметические операции |
| **Сравнение** | `LESS`, `GREATER`, `EQUAL`, `NOT_EQUAL` | `<`, `>`, `==`, `!=` | Операции сравнения (требуют Lookahead) |
| **Разделители** | `SEMICOLON`, `COMMA` | `;`, `,` | Конец выражения / разделитель параметров |
| **Скобки** | `LPAREN`, `RPAREN`, `LBRACE`, `RBRACE` | `(`, `)`, `{`, `}` | Ограничители выражений и блоков кода |
| **Комментарии** | *(Игнорируются)* | `// ...`, `/* ... */` | Пропускаются лексером при сканировании |
| **Служебные** | `END_OF_FILE`, `UNKNOWN` | `\0` | Маркер конца файла или синтаксическая ошибка |

---

### 3. Комментарии в языке
Лексер поддерживает два типа комментариев, которые автоматически отфильтровываются и не попадают в итоговый AST:
- **Однострочные комментарии:** Начинаются с `//` и продолжаются до конца текущей строки (`\n`).
- **Многострочные комментарии:** Начинаются с `/*` и продолжаются до закрывающей пары `*/`.

---

### 4. Формальная грамматика (EBNF)

Синтаксис языка описывается контекстно-свободной грамматикой в форме EBNF:


Program        ::= Statement*
Statement      ::= VarDeclStmt | IfStmt | WhileStmt | ExprStmt ";"
VarDeclStmt    ::= "var" IDENTIFIER "=" Expression ";"
IfStmt         ::= "if" "(" Condition ")" "{" Statement* "}"
WhileStmt      ::= "while" "(" Condition ")" "{" Statement* "}"
Condition      ::= Expression ( "<" | ">" | "==" | "!=" ) Expression
Expression     ::= Term ( ( "+" | "-" ) Term )*
Term           ::= Factor ( ( "*" | "/" ) Factor )*
Factor         ::= NUMBER | IDENTIFIER | CallExpr | "(" Expression ")"
CallExpr       ::= IDENTIFIER "(" ( Expression ( "," Expression )* )? ")"

### 5. Пример исходного кода(.dsl)
// Инициализация переменных
var x = 0;
var limit = 5;

/* 
   Демонстрация цикла while 
   и условного оператора if
*/
while (x < limit) {
    if (x != 3) {
        print(x);
    }
    x = x + 1;
}
