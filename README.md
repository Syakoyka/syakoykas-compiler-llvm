syakoykas-compiler-llvm
A custom Domain-Specific Language (DSL) compiler written in C++ using LLVM API.

C++ / LLVM DSL Compiler

Курсовой проект по учебной дисциплине Конструирование Программного Обеспечения(2 курс): разработка компилятора для простого предметно-ориентированного языка программирования (DSL). Программа выполняет лексический и синтаксический анализ исходного кода, строит абстрактное синтаксическое дерево (AST) и генерирует промежуточное представление LLVM IR.

Структура конвейера

1. Lexer — разбивает входной поток символов из файла `.dsl` на токены.
2. Parser — синтаксический анализатор, формирующий дерево AST.
3. CodeGen — генерация LLVM IR с использованием LLVM C++ API (`llvm::IRBuilder`).

Стек технологий

* C++17 (MSVC / GCC)
* LLVM API
* CMake 3.16+

Пример исходного кода (.dsl)

var x = 10;
var y = 20;

if (x < y) {
    print(x + y);
}
