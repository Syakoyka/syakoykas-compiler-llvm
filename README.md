# syakoykas-compiler-llvm

> **Курсовой проект** по учебной дисциплине «Конструирование Программного Обеспечения» (2 курс).  
> **Тема:** Разработка компилятора для простого предметно-ориентированного языка программирования (DSL).

---

**Описание проекта**

Проект представляет собой компилятор для узкоспециализированного языка программирования (DSL), написанный на **C++17** с использованием библиотеки **LLVM C++ API**. Компилятор выполняет полный цикл трансляции: от лексического анализа исходного текста до генерации промежуточного представления LLVM IR.

---

**Архитектура и структура конвейера**

Трансляция кода выполняется в три основных этапа[cite: 1]:

1. **Lexer (Лексический анализатор):** Читает исходный текст из файла `.dsl` и разбивает его на поток токенов[cite: 1].
2. **Parser (Синтаксический анализатор):** Анализирует последовательность токенов на соответствие грамматике и строит абстрактное синтаксическое дерево (**AST**)[cite: 1].
3. **CodeGen (Генератор кода):** Обходит AST и генерирует промежуточный код **LLVM IR** с помощью `llvm::IRBuilder`[cite: 1].

---

**Спецификация входного DSL-языка**

### 1. Алфавит языка
Алфавит языка включает следующие допустимые категории символов:
- **Буквы латинского алфавита:** `a–z`, `A–Z`[cite: 2]
- **Десятичные цифры:** `0–9`[cite: 2]
- **Специальные символы:** символ подчёркивания `_`[cite: 2]
- **Знаки операций и сравнения:** `=`, `+`, `-`, `*`, `/`, `<`[cite: 1, 2]
- **Разделители и пунктуация:** `;`, `,`, `:`, `(`, `)`, `{`, `}`[cite: 1, 2]
- **Пробельные символы:** пробел, табуляция (`\t`), перенос строки (`\n`, `\r`)[cite: 2]

---

**2. Спецификация лексем (Lexical Tokens)**

> 💡 **Особенность реализации:** Лексический анализатор реализован **вручную** на C++ (метод сканирования на базе Детерминированного Конечного Автомата — ДКА). 
> Использование библиотек регулярных выражений (`std::regex`) **отсутствует**, что обеспечивает высокую скорость работы и точный отсчёт позиций (строка/колонка) при обработке ошибок[cite: 2, 3].

В таблице ниже приведено формальное описание паттернов лексем (в виде регулярных выражений для теории):

| Категория токена | Тип токена (`TokenType`) | Примеры лексем | Формальный паттерн (Theory) |
| :--- | :--- | :--- | :--- |
| **Ключевые слова** | `VAR`, `IF`, `PRINT` | `var`, `if`, `print` | `var`, `if`, `print` |
| **Идентификаторы** | `IDENTIFIER` | `x`, `y`, `sum_val` | `[a-zA-Z_][a-zA-Z0-9_]*` |
| **Числовые литералы** | `NUMBER` | `0`, `10`, `20` | `[0-9]+` |
| **Оператор присваивания** | `ASSIGN` | `=` | `=` |
| **Арифметические знаки** | `PLUS`, `MINUS`, `STAR`, `SLASH` | `+`, `-`, `*`, `/` | `+`, `-`, `*`, `/` |
| **Сравнение** | `LESS` | `<` | `<` |
| **Разделители** | `SEMICOLON`, `COMMA` | `;`, `,` | `;`, `,` |
| **Скобки** | `LPAREN`, `RPAREN`, `LBRACE`, `RBRACE` | `(`, `)`, `{`, `}` | `(`, `)`, `{`, `}` |

### 3. Формальная грамматика (EBNF)

Синтаксис языка описывается следующей контекстно-свободной грамматикой[cite: 1]:

```ebnf
Program        ::= Statement*
Statement      ::= VarDeclStmt | IfStmt | ExprStmt ";"
VarDeclStmt    ::= "var" IDENTIFIER "=" Expression ";"
IfStmt         ::= "if" "(" Condition ")" "{" Statement* "}"
Condition      ::= Expression "<" Expression
Expression     ::= Term ( ( "+" | "-" ) Term )*
Term           ::= Factor ( ( "*" | "/" ) Factor )*
Factor         ::= NUMBER | IDENTIFIER | CallExpr | "(" Expression ")"
CallExpr       ::= IDENTIFIER "(" ( Expression ( "," Expression )* )? ")"
