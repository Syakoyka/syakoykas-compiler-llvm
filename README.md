# syakoykas-compiler-llvm

Курсовой проект по дисциплине «Конструирование программного обеспечения» (2 курс). Разработка фронтенда компилятора для предметно-ориентированного языка (DSL) с использованием C++17 и инфраструктуры LLVM.

## Статус реализации
На текущем этапе реализован лексический анализатор (определенная его часть с не всем кол-вом запланированных токенов) на основе детерминированного конечного автомата с табличной реализацией переходов. Модули синтаксического анализа и генерации кода находятся в разработке.

## Архитектура лексера
Лексер производит сканирование исходного текста и преобразование его в поток лексем с помощью матрицы состояний:
- **Алфавит и типы символов (`CharType`):** разделение входного потока на буквы, цифры, операторы и разделители.
- **Табличный DFA (`Transitions`):** детерминированный автомат с явной матрицей переходов и массивом финальных состояний.

### Поддерживаемые токены (`TokenType`)
- **Ключевые слова:** `def`, `if`, `else`
- **Идентификаторы:** пользовательские имена переменных и функций
- **Числовые литералы:** целые числа
- **Операторы:** базовые арифметические знаки и операции присваивания (`+`, `-`, `=`, `<`, `>`)

Пробельные символы автоматически игнорируются. Некорректные символы классифицируются как ошибки лексического анализа.

## Структура проекта
- `include/lexer.hpp` — спецификация типов токенов, состояний автомата и интерфейс класса `Lexer`.
- `src/lexer.cpp` — реализация алгоритмов токенизации и табличного DFA.
- `src/main.cpp` — точка входа с базовыми тестами для проверки лексера.
- `examples/` — директория с примерами исходного кода на DSL.
